# SyncForge

A Linux-based file synchronization and change detection utility implemented in C.

## Overview

SyncForge is a command-line utility designed to compare two directory
trees, identify differences between them, and synchronize the destination
directory with the source.

The project is being developed as a systems programming project in C,
with a focus on Linux filesystem operations, file metadata, directory
traversal, file I/O, and change detection.

## Objectives

- Understand Linux filesystem operations
- Implement recursive directory traversal
- Work with file metadata
- Detect differences between directory trees
- Synchronize files and directories
- Practice low-level file I/O in C
- Develop a modular C project using Linux/POSIX APIs

## Planned Features

- Recursive directory scanning
- File metadata collection
- New file detection
- Modified file detection
- Deleted file detection
- File synchronization
- Dry-run mode
- Content verification
- Conflict detection
- Synchronization logging
